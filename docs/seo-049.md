## Production and preview settings

The previous package defaulted to noindex with an empty sitemap. This release includes `.env.production` with the existing canonical domain `https://www.midnightstudios.app` and `SITE_INDEXABLE=true`. A normal production build now allows indexing and produces all eleven published content URLs in its sitemap. Confirm that this is the domain you will actually publish to; change it and rebuild if necessary. This is configuration for publication, not evidence that the website has been deployed or indexed.

Development stays noindex. Set `SITE_INDEXABLE=false` for private review builds. Vercel preview deployments and Netlify deploy-preview/branch-deploy builds also force noindex. A static export cannot change metadata according to its eventual host: rebuild for each audience. Avoid copying the optional localhost `.env.example` to `.env.local` when preparing a public deployment; local overrides take precedence.

## After publishing

Verify ownership in Google Search Console, submit `/sitemap.xml`, and inspect the homepage URL. Make sure the host serves pages, images, robots and sitemap publicly over HTTPS with successful HTTP status codes; remove hosting-level noindex headers for the intended public site. Redirect alternate domains and old equivalent URLs to the canonical ones. Share the public URL: a localhost link cannot produce a public preview. Platforms may cache previously shared previews until they refresh them.

Continue publishing useful development stories and keep accurate links from official profiles. Rankings depend on publication, crawling/indexing, relevance, competition and links. No first-place placement, exact snippet wording, rich result, or timeline is guaranteed. Google may use page text instead of the supplied description. Browser/device rendering and live PageSpeed/Core Web Vitals were not measured in this environment.
