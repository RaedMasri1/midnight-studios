# Client review copy audit — 0.4.8

The review covered the rendered Home, Games, About, Contact, Journal, article, and all five game detail pages, plus their navigation, media captions, footer and inactive review states. The aim was to keep useful information and give every sentence a clear purpose.

| Page or area | Kept | Changed or removed, with reason |
| --- | --- | --- |
| Home hero | “Imagination never sleeps”, studio identity, both navigation actions | Consolidated “Independent game studio. Care in every detail.” into the small line above the headline. Removed the adjacent repeated studio description. |
| Home game chapters | Every game, status, genre, animation and detail link | One shared status → genre → game name → description → action structure. Replaced the oversized Just Jump marketing headline and Dreamward’s generic introduction with their game names. Removed the second status beneath the Jump button. |
| Just Jump copy | Endless climbing, characters, abilities, upgrades, cosmetics, forest/cliff and cave worlds | “Time the next leap. Unlock your favorite jumper and climb from sunlit cliffs to glowing crystal caves.” It describes the play rather than listing “Original characters. New environments.” |
| Dreamward copy | Ancient spells, strategic upgrades, moonlit fantasy | Describes those mechanics rather than “A new adventure in the making.” |
| Break the Heel copy | Smashing blocks beneath heels, districts, fashionable unlocks | Shortened the description around the player’s actions. Removed the generic “A fun and stylish casual game where players…” opening. |
| Tadri copy | Multiplayer, friends, hundreds of categories and the supplied topics | Led with the challenge between friends. Retained the broader topic list in the detail page. |
| Idle Chaos copy | Disasters, destructive upgrades and escalation | Led with a disturbance growing into a storm. No new gameplay systems were added to the claims. |
| Home studio section | “Play is in the details”, process stages and their captions | Kept “From the first idea to the last detail” and aligned its block to the right. These lines explain the existing sequence. |
| Home Journal | Story title, summary, topic and reading link | Kept the editorial information. The request here was section height, not arbitrary text removal. |
| Games index | Collection heading, linked covers, descriptions, statuses and journal link | Replaced a generic list of “original characters/different ways to play” with a short description of the range of games. Standardized the detail-link wording. |
| All game detail pages | Game/developer identity, release status, meaningful overview, features and all media | Removed repeated “official artwork and details will be shared when ready” paragraphs. Concept material remains clearly captioned. Galleries containing only concept art now say “Artwork”, not “Screenshots”. |
| Inactive game review states | All review data, components and future sign-in behavior | Empty review sections are hidden when there are no reviews and no sign-in service configured. This avoids a client-facing form that can only say reviews are unavailable. Reviews return when records exist or sign-in is configured. |
| About | Qatar location, origin story, two years of development, developer/artist collaboration, studio values and attributed quote | Condensed the story without changing its facts. Removed the repeated location beneath the story heading. Expanded the introduction beyond mentioning only two of the five games. |
| Contact | Email address, email action, studio/About and Journal links | Removed the redundant “Contact the studio” eyebrow and numbered headings. Shortened the invitation and made the supporting headings more concrete. The readable email address remains available for copying. |
| Journal index | Journal heading, story card and reading action | Shortened the introductory sentence to “The decisions, redesigns, and lessons behind our games.” |
| Journal article | Entire article, development details, financial figures, attribution, caveat and game link | Retained unchanged. These are substantive reporting rather than decorative filler. |
| Global footer | Contact action, moon, company identity, copyright and slogan | Slogan is “Imagination never sleeps” with no period or forced line break. Removed the extra contact eyebrow and public version suffix. Release identity remains in VERSION.txt, the launcher and /__version. |
| Navigation and accessibility | Page links, breadcrumbs, current-page states, skip links, meaningful alt text and controls | Retained. These support navigation and accessibility. |

The adapted tablet pictures are labelled “Gameplay visualization” on the homepage. The real phone development screenshots remain unchanged in the Just Jump gallery. No invented review, release date, award, download count, rating or game feature was introduced.
